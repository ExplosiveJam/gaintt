# 05 — Правка плана через чат

**What to build:** Рядом с диаграммой появляется чат. Пользователь пишет «перенеси
интеграцию с платежами на неделю» — план меняется, диаграмма показывает новое
расписание, в чате появляется список того, что изменилось.

Пока Agent работает, диаграмма неподвижна, а в чат стримятся нейтральные стадии
(«анализирую → проверяю → применяю»). Конкретные намерения до успешного коммита не
показываются: обещать правку, а потом откатить ход — значит соврать пользователю.

Agent не имеет прямого доступа к состоянию: он читает снимок Plan и пишет только
через MCP-тул `apply_turn`, вызываемый in-memory транспортом внутри того же
процесса (ADR-0001).
