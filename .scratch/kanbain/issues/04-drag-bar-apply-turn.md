# 04 — Перетаскивание бара

**What to build:** Пользователь тянет бар задачи мышью и отпускает — задача
получает Pinned Start, зависимые задачи разъезжаются сами, диаграмма показывает
новое расписание. Попытка утащить задачу раньше её предшественника не ломает план
и просто не даёт эффекта: Pinned Start — ограничение «не раньше», а не «ровно
тогда».

Здесь появляется `apply_turn(plan_id, base_version, mutations[])` — единственный
способ записи в Plan для всего приложения. Отдельных мутирующих операций в
контракте нет: конкретные правки живут вариантами внутри `mutations[]`. Версия
Plan монотонно растёт, запись с устаревшей версией отклоняется.

**Blocked by:** 03 — Сид-план на диаграмме.
