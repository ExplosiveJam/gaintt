# 08 — Импорт Excel с отчётом

**What to build:** Пользователь загружает свой файл с колонками задача, описание,
исполнитель, длительность, предшественники — и видит план на диаграмме плюс отчёт
вида «загружено 18 задач из 20, вот что не получилось». Импорт снисходителен:
берём всё, что понятно, а непонятное называем вслух. Отчёт — часть результата, а
не запись в логах: молча потерянная связь хуже, чем названная.

Заголовки распознаются по словарю синонимов (русские и английские, любой регистр,
лишние пробелы) — это единственное место локализации во всём приложении.

**Blocked by:** 03 — Сид-план на диаграмме.

**Status:** implemented

- [x] Заголовки распознаются по словарю синонимов; на нераспознанные — понятная ошибка со списком найденного
- [x] Несколько предшественников в ячейке разделяются запятой, точкой с запятой и переносом строки
- [x] Ссылка на несуществующее название отбрасывается и попадает в отчёт
- [x] При дублирующихся названиях импортируются обе задачи, а связь по неоднозначному имени отвергается явно
- [x] Цикл внутри файла разрывается по замыкающей связи, разорванная связь названа в отчёте
- [x] Пустая или нечисловая длительность обрабатывается и попадает в отчёт
- [x] Загруженный план заменяет текущий и сразу виден на диаграмме
- [x] Тесты на seam'е импорта: по одному на каждый вид грязных данных, проверяется и план, и отчёт
- [x] В репозитории лежит пример Excel для теста
