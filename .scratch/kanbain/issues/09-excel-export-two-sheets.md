# 09 — Экспорт Excel в два листа

**What to build:** Пользователь выгружает план обратно в Excel и получает файл с
двумя листами. «План» — исходный формат плюс колонки Pinned Start и Due Date; этот
лист можно загрузить обратно и получить тот же самый план. «Расписание» —
вычисленные даты для человека, который понесёт файл заказчику и не должен считать
их из длительностей сам.

Точный round-trip — это не удобство, а доказательство, что домен замкнут: файл
остаётся полноценным носителем состояния.

**Blocked by:** 08 — Импорт Excel с отчётом.

**Status:** implemented

- [x] Лист «Расписание» содержит вычисленные даты начала и конца, последний день показан включительно
