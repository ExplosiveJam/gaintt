# 12 — Smoke-тест главного сценария

**What to build:** Главный сценарий продукта — загрузка Excel, правка через чат,
выгрузка обратно — проверяется автоматически, а не глазами перед отправкой. Один
браузерный тест с замоканным LLM, который ходит по тому же пути, по которому
пойдёт ревьюер.

Один такой тест ценнее нескольких инфраструктурных: он страхует ровно то, поломка
чего обесценивает всю работу.

**Blocked by:** 06 — Массовая правка и самоисправление агента; 09 — Экспорт Excel
в два листа.

**Status:** implemented

- [x] Тест загружает пример Excel, делает правку через чат и выгружает результат
- [x] LLM замокан: тест не ходит в сеть и не зависит от квоты
- [x] Проверяется, что правка отразилась на диаграмме, а не только вернулась ответом
- [x] Тест запускается одной командой вместе с остальными
