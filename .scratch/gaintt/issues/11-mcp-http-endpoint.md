# 11 — HTTP-эндпоинт MCP за флагом

**What to build:** Разработчик со своим MCP-клиентом (например, MCP Inspector)
подключается к работающему приложению по HTTP и видит тот же набор тулов, которым
пользуется внутренний Agent. Это то, что делает MCP в проекте настоящим
интерфейсом, а не внутренней деталью: контракт домена один и тот же для своих и
чужих.

Эндпоинт включается флагом окружения и по умолчанию выключен. Мутирующий MCP без
авторизации наружу не выставляется.

**Blocked by:** 05 — Правка плана через чат.

**Status:** implemented

- [x] HTTP-эндпоинт MCP включается флагом окружения, по умолчанию выключен
- [x] Внешний клиент видит те же тулы, что и внутренний Agent
- [x] Без авторизации мутирующие тулы наружу не доступны
- [x] Внутренний Agent продолжает ходить in-memory транспортом, без сетевого хопа
- [x] В README описано, как подключиться внешним клиентом
