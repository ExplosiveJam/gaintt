# 07 — Откат хода агента

**What to build:** У каждой реплики Agent'а в чате есть кнопка «откатить». Нажатие
возвращает Plan к состоянию до этого хода — целиком, включая все тридцать правок.
Это снимает главный страх пользователя AI-продукта: дать агенту массовую правку и
не суметь её отменить.

Кнопка гаснет, как только поверх хода легло любое изменение: откат разрешён,
только если версия Plan с тех пор не менялась. Так откат никогда не затирает более
свежую работу и не требует разбирательства, что с чем совмещать.

**Blocked by:** 05 — Правка плана через чат.

- [x] Откат возвращает план к снимку и увеличивает версию
- [x] Откат отклоняется, если версия изменилась после хода
- [x] Кнопка отката видна у реплики агента и гаснет, когда откат больше не разрешён
- [x] Тесты: успешный откат, отказ при изменившейся версии, откат хода из множества мутаций
